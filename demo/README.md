# DynaSense · 动手体验 / Try DynaSense

[中文操作引导](GUIDE.zh.md) · [English walkthrough](GUIDE.en.md)

打开 `materials.k`，从一张材料卡开始。
Open `materials.k` and start with a material card.

1. **编辑字段 / Edit fields** — 将光标放入材料参数，使用 Tab 选中字段，修改数值并撤销。 / Place the cursor in a material parameter, use Tab to select a field, change its value, then undo.
2. **查阅帮助 / Read help** — 在字段上查看帮助，打开对应手册章节，切换中文、英文和双语阅读。 / Inspect field help, open the corresponding manual chapter, and try English, Chinese and bilingual reading.
3. **管理卡片 / Manage a card** — 打开卡片管理器，修改一个字段，应用并检查文档，再撤销。 / Open the card manager, edit a field, apply the change, inspect the document, then undo.
4. **沿模型导航 / Navigate the model** — 打开 `main.k`，展开 Include；从部件找到其材料，再查看对象引用。 / Open `main.k`, explore its includes, follow a part to its material, and inspect entity references.
5. **看清修改 / Review changes** — 修改并保存，然后查看本次打开以来的差异。 / Edit and save, then inspect changes since the file was opened.
6. **尝试补全 / Try completion** — 在空白行输入关键字前缀，选择候选，再撤销。 / Enter a keyword prefix on a blank line, accept a suggestion, then undo.

案例来源：DYNAmore Drop Test 的 Reduced Input。原始数值保留；文件拆分和字段注释为体验组织。
Source: the Reduced Input of the DYNAmore Drop Test. Numeric values are preserved; file splitting and field-label comments organize the experience.
